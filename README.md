# Customer Management System (CRM) - Login, Register & Dashboard

Aplikasi **Customer Management System (CRM)** dengan halaman Login, Pendaftaran, dan Halaman Dashboard Utama.

## Struktur File
- `index.html` : Halaman Masuk (Login) tanpa tampilan log aktivitas.
- `register.html` : Halaman Pendaftaran (Registrasi akun baru).
- `dashboard.html` : Halaman Utama Dashboard CRM (Kartu Metrik, Tabel Pelanggan, Sidebar Navigasi & Profil).
- `style.css` : Styling terpusat untuk antarmuka autentikasi dan dashboard.
- `script.js` : Logika alur autentikasi, proteksi halaman, penyimpanan sesi, dan sistem keluar (logout).

## Cara Menjalankan
1. Ekstrak file ZIP.
2. Upload ke GitHub Repository Anda.
3. Buka `index.html` untuk masuk (Kredensial bawaan: `admin@crm.com` / `password123`) atau daftar akun baru melalui `register.html`.
